# Paper

`paper.pdf` is the camera-ready version; `paper.tex` its source (ACL style).

Build with pdfLaTeX and BibTeX:

```bash
pdflatex paper && bibtex paper && pdflatex paper && pdflatex paper
```

- `acl.sty`, `acl_natbib.bst`: ACL style files.
- `references.bib`: bibliography.
- `figures/`: Figures 1 and 2, generated by `src/visualize.py` from `results/`.
- `arabic/`: Arabic snippets in the examples table, pre-rendered with LuaLaTeX (`arabic/build.sh`) so that the
  paper itself compiles with pdfLaTeX.
